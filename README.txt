DANIEL & DILARA — UPDATED FINAL GITHUB PAGES PACKAGE

This ZIP uses the latest index.html and style.css files supplied by you, plus the production
script.js that switches to the post-wedding page at midnight on 25 October 2026 in Istanbul.

INSTALL:
1. Back up your current repository files.
2. Extract this ZIP.
3. Replace index.html, style.css, and script.js in the GitHub repository with the three files
   from this ZIP. This package includes your updated style.css, so use this version.
4. Commit the changes.
5. Check the GitHub Pages site with a hard refresh (Ctrl+F5).

The script is production mode, NOT preview mode. Before 25 October 2026 in Istanbul it should
show the invitation. From 25 October onward it hides the countdown/location/RSVP controls and
shows the thank-you copy and Google Photos album button.

The existing site URL and QR code remain the same.
